# Changelog

All notable changes to **sql2sqlx** are documented here. This project has not
been released yet. The first planned release is `0.1.0`.

## [0.1.0] - Unreleased

### Added
- Initial BigQuery SQL to Dataform SQLX conversion pipeline.
- GoogleSQL lexer, scripting-aware statement splitter, statement classifier,
  reference scanner, dependency linker and SQLX emitter.
- CLI, typed Python API, examples, Sphinx documentation and regression tests.
